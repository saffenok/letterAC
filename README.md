# Письмо для аудиторской компании
Письмо, базовые блоки которого собраны в конструкторе Unisender, а внешний вид скорректирован вручную в исходном коде (блок с облаком тегов в разделе "О нас", углы скругления, корректные отступы, стрелки, цвета и т.п.). Также в исходном коде были исправлены баги, из-за которых письмо отображалось некорректно в Outlook
